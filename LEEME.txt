NEXUS — versión reescrita a HTML + CSS + JS
============================================

Esta carpeta es código fuente legible, escrito a mano.
NO usa React, NO usa TypeScript, NO necesita npm ni build.

Archivos:
  index.html  -> estructura de la página (secciones, formulario, modal).
  styles.css  -> todos los estilos, animaciones y responsive.
  app.js      -> datos, editor animado, demos y formulario.
  assets\     -> logo, favicon.svg e imágenes de la demo del estudio jurídico.
  kchick\     -> landing K-CHICK original (HTML/CSS/JS) que se abre en un iframe.

CÓMO PUBLICAR
-------------
Subí TODO el contenido de esta carpeta a la raíz pública del hosting.
index.html debe quedar en la raíz, con assets\ y kchick\ al lado.

Sirve para Netlify Drop, Vercel, GitHub Pages, cPanel/FTP o cualquier hosting estático.
Las rutas son relativas (./assets/..., ./kchick/...), así que también funciona en subcarpetas.
